Productizing Muse: Three Open Questions, Answered

source: laura-jay-craig session 2026-09-14 · delivered 2026-11-02

The case: a casino inspector walks the floor, captures photos on-site, dictates observations by voice, and the system generates compliance documentation. What used to take a month now takes an hour. 1 month → 1 hour. That's the pattern to productize.

Q1 — Native app vs web app for on-site capture

VERDICT: START WEB, EARN YOUR WAY TO NATIVE

A web app (or PWA) gives you zero-install onboarding, instant iteration, and one codebase — critical when you're still discovering what the workflow even is.

  • You only need native at its hard edges: unreliable venue Wi-Fi (offline-first sync), deep camera hardware access, background capture, or push notifications field workers will actually see.
  • The casino floor likely has all of these — but build the pipeline first, then wrap it in native when the capture constraints are proven, not before.
  • A PWA gets you 80% of the way and keeps your iteration speed.

Q2 — Agent-to-agent communication for doc-generation pipelines

VERDICT: START WITH A SINGLE AGENT + TOOLS

The workflow is really three stages: capture (photo + dictation → raw multimodal input), structuring (LLM maps raw input onto compliance fields/templates), and generation (formatted doc output with human review).

  • Multi-agent pipelines shine when stages need different context windows, different models, or independent review — e.g., a structuring agent that never sees the compliance rulebook vs a review agent that only checks against it.
  • But every agent boundary you add is another failure point and another handoff to debug.
  • Add agents when a stage genuinely outgrows the single-agent context — not for architecture aesthetics.

Q3 — Onboarding non-technical users into AI workflows

VERDICT: TRUST IS BUILT BY SHOWING THE MACHINE'S WORK

The inspector doesn't care about AI — they care about going home earlier.

  • One-task-first onboarding: capture one inspection in the first session, see the doc generated immediately.
  • Voice-first input — never make a non-typer type.
  • Templates as training wheels: start from a known compliance doc format so output looks familiar.
  • Always show the raw input next to the generated output so they learn to trust it.
The Pattern Underneath All Three

Move the formatting burden off the human and onto the system. The 1-month → 1-hour gain didn't come from better inspection — it came from the inspector never touching a document. That's the Muse thesis, and it generalizes.
