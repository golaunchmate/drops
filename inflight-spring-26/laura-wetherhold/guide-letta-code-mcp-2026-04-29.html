🚀 Letta Code MCP Integration

A Step-by-Step Guide for LaunchMate
GUIDE

Overview

This guide walks you through integrating Letta Code (desktop) with LaunchMate's context engine via Model Context Protocol (MCP). By the end, you'll have a local agent that can ingest transcripts, create drops, and sync with your cloud LaunchMate agent.

Installation Steps

1

Install Letta Code

Download Letta Code desktop app from letta.com. This gives you local agent execution with file system access.

# Verify installation
letta --version
2

Configure MCP Server

Set up the MCP (Model Context Protocol) server to connect Letta Code to external services like Granola, GitHub, and LaunchMate cloud.

# mcp_config.json
{
  "servers": [
    {
      "name": "granola",
      "command": "granola-mcp-server",
      "args": ["--api-key", "${GRANOLA_API_KEY}"]
    },
    {
      "name": "github",
      "command": "github-mcp-server",
      "args": ["--token", "${GITHUB_TOKEN}"]
    }
  ]
}
3

Connect Transcript Agent

Configure your local Letta Code agent to communicate with the cloud Transcript Agent. This enables the transcript→drop workflow.

# In your Letta Code agent system prompt:
"You are connected to LaunchMate's transcript pipeline.
When you receive transcript analysis:
1. Display summary to user
2. Send structured data to Drop Agent (agent-82720585-edcc-4c31-b558-68fe3183b1e7)"

Workflow Example

Here's what happens when you finish a meeting:

  1. Meeting ends → Granola records transcript
  2. Transcript Agent (local) analyzes via MCP
  3. Drop Agent (cloud) receives insights, creates scheduled drops
  4. Artifact stored in drops repo (GitHub)
  5. Notification sent to your agent when drop is ready

Key Integration Points

  • Granola MCP: Pull meeting transcripts
  • GitHub MCP: Store artifacts in drops repo
  • Discord MCP: Optional notifications
  • LaunchMate Cloud: Agent-to-agent communication
